# Horizon Explorer

An original, browser-based meditative driving experience built with Three.js and Vite. Explore a procedural-feeling landscape, find landmarks, and capture quiet moments.

## Play locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Controls

- **W / S** — accelerate / reverse
- **A / D** — steer
- **Space** — brake
- **F** — photo mode
- **R** — reset the rover

## Current vertical slice

- Stylized 3D terrain with a winding road, vegetation, rocks, fireflies, and original landmarks
- Custom electric rover assembled from procedural geometry
- Driving physics, camera follow, braking, boundaries, and reset
- Discovery moments with biome and distance HUD
- Photo mode with PNG capture
- Responsive start screen and mobile-friendly layout

The project is deliberately asset-free: the visual identity is generated from code so it can evolve into a larger original world without borrowing protected game assets.
